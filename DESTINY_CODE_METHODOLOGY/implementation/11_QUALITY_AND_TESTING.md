# Validation: completed portable checks and future application checks

Run from the package root:

```bash
node reference/validate.mjs
python3 reference/validate_data.py
```

Python data validation uses jsonschema. The Node reference uses only built-in modules. It does not require Next.js, a model API, payment credentials, a production build, or a browser.

- Twelve date fixtures with complete38-value outputs and every operand/reduction step; single/double digit days, threshold22/23, month/year boundaries, leap dates, repeated values and an additional sample-era date.
- Independent Python arithmetic exports versus the Node calculator, including alternate ancestry results and exact trace equality.
- Strict Gregorian inputs, including1900 non-leap,2000 leap, malformed dates, timestamps, zero years and invalid day/month values.
- R22 keeps all 1–22; reduces23→5 and29→11; rejects invalid numbers. A partial-sum counterexample prevents an associative-reduction bug.
- All 38 formula IDs,30 diagram nodes,22 archetypes, source page references and report/channel dependencies resolve. Each active domain has copy for every archetype.
- C tail keys retain exact role order, including three distinct9/9/18 variants. Generic-code matchers stay disabled.
- A narrow free DTO contains only its declared fields. This is not a substitute for authorization tests in the real application.
- Same-date composition is deterministic and different sample dates change the actual values and generated reading. The public sample is generated by the same portable model as other readings.

Inspect `data/reference_validation_results.json` and `data/data_validation_results.json` for actual results. Generated fixtures verify arithmetic regression; they do not validate the esoteric claims.

## Editorial review rubric

A section passes when it states the actual position and value, explains a distinct domain-specific meaning, makes source/editorial status clear, and gives a conditional example or useful practice. It fails if it reads the same general paragraph at every node, asserts contradictory facts about the person, invents a position or program, reverses8/11, diagnoses a shadow state, or repeats a whole profile to inflate length.

Phrase contrasts as possibilities with a clear distinction of roles. A repeated archetype is structural recurrence, not independent corroboration. A reader must be able to locate a generated conclusion's node, formula, symbolic library entry and composition rule. All 630 pages were processed, but the coverage log explicitly declines an exhaustive semantic-read claim.
