# Report design derived after research

The methodology determines available positions. Report organization is a separate editorial decision. The proposal has ten topical chapters and one technical appendix, not an inherited fixed count. Exact machine-readable membership and rules are in `data/report_sections.json`.

|---|---|---|---|

## Depth and editorial discipline

Each topical section needs a role-specific interpretation, a constructive/shadow contrast, a practical example and an identifiable conclusion. A short section is preferable to duplicated profiles. There is no required number of words. Generic archetype descriptions should appear at most once in full; later sections use the relevant domain sentence and explain the changed role.

Both reading levels derive from one report model. Source facts, original composition and missing evidence are distinguishable in the advanced layer. The public sample and both PDF themes must use this same model. The technical appendix is useful evidence, not a place to compensate for thin topical interpretation.
