# Combination and composition rules

A named pattern, an arithmetic channel, and an original composition rule are separate objects. A plausible English sentence does not prove a traditional combination exists.

## Supported numeric ordering

C:226 tail order is bottom→inner→middle. C:141 describes root-first program reading. Source A/B use other enumerations and catalog conventions. Never sort a tuple or match its multiset to borrow a name.

## Rules

### COM-CHANNEL

Origin: editorial_synthesis. Inputs: declaredChannel, nodeValues, domainReadings.

Only channels.json entries, not arbitrary visually adjacent triples.

State the anchor/entry theme, then the supporting or balancing theme, then the channel-specific midpoint. All nodes retain their role. Avoid repeating a whole archetype profile.

Example: A 3 entry suggests examining tangible care and resources; a 21 midpoint adds broad or cross-context work settings; an 18 bridge calls for clarifying assumptions between partnership and money.

Limitations: This is original report composition. It does not certify a named traditional program.

### COM-REPEAT

Origin: editorial_synthesis. Inputs: primaryNodeIds, nodeValues.

The nine primary nodes only: day, month, year, bottom, core, nw, ne, se, sw.

Group equal values across distinct nodes. Mention at most two recurring themes, with every contributing node listed. Interpret as structural recurrence; dependent sums are not independent evidence. Do not count channels, report occurrences, family_center or purposes as more primary observations.

Example: The same 5 appears at bottom and ne. Learning appears both as a personal challenge theme and a maternal upper-branch theme. This does not show that your mother had that trait.

Limitations: No power score, multiplier, probability or diagnosis.

### COM-CONTRAST

Origin: editorial_synthesis. Inputs: explicitContrastPairs, selectedNodeValues.

Only the listed pairs in contrast_pairs.json and only within one section's declared nodes.

Present two useful preferences and a tradeoff; offer a conditional behavior example and a practical agreement. Never decide that one cancels the other. Use at most one contrast per section.

Example: Structure (4) and exploration (22) can be negotiated through stable commitments and a bounded experiment.

Limitations: No conflict score and no claim that a person actually experiences the tradeoff.

### COM-BALANCE

Origin: editorial_synthesis. Inputs: year_inner, money_center, bridge, bottom_inner, love_center.

The shared relationship–money bridge.

Explain the bridge once as the place where resource and relationship commitments meet; link back to it in both sections.

Example: If uncertainty is the bridge theme, distinguish the shared facts about time and money from expectations each person assumed.

Limitations: No wealth forecast or meeting-place prediction.

### COM-TAIL-C

Origin: source_specific. Inputs: bottom, bottom_inner, bottom_mid.

Exact ordered C key only.

Look up karmic_patterns.json by the three named roles in calculation order. If absent, use the bottom archetype as a general learning theme and explicitly state that no named pattern was matched.

Example: For 1991-12-09, 5-15-20 matches TAIL-C-5-15-20. Physical order 5-20-15 is different and is not a lookup key.

Limitations: No sorting, reversing, or multiset matching. No literal accusation about a past life.

### COM-TALENT-WORK

Origin: editorial_synthesis. Inputs: month, month_inner, month_mid, money_center.

Talents and work chapter.

Offer one practical work experiment joining a talent-related practice with the resource midpoint theme; display both underlying roles.

Example: Expression through service (12) with a broad coordination theme (21) could be explored by making one useful guide for a specific new audience.

Limitations: An exploration, not an assurance of income or professional fit.

## Tail catalog

The 26 entries in data/karmic_patterns.json have C page references and exact role tuples. English titles and reflections are new editorial content; source labels alleging historical crimes or diagnoses are not shown. In particular, 18–9–9, 9–9–18 and 9–18–9 remain separate.

## Generic program catalog is intentionally not an active rules engine

The extracted generic C code headings are in data/source_code_catalog.json. A boolean records whether each heading satisfies an anchor+inner→middle relation or its alternative relation. Those checks are research diagnostics, not a license to permute or repair the printed key. A placement-specific detector and orientation mapping are unresolved, so automaticMatchingEnabled=false for every entry.

## Deterministic personalization

Personalization is produced by actual node values, node roles, exact channel membership, the ordered tail key, structural recurrence and a bounded explicit contrast table. The library does not manufacture all 231 unordered pairs or 10,648 triples as predictions. A fixed date, fixed data revision and fixed locale produce identical output. Optional future language-model polishing must not introduce new facts or change calculations.
