# DESTINY CODE — independent methodology research and separate Codex handoff

## Результат

Подготовлена самостоятельная методическая основа по трём загруженным книгам, без опоры на текущие девять позиций, восемь глав или существующие формулы приложения. Сначала зафиксированы источники и расхождения, затем выбрана связная расчётная система; техническое задание находится отдельно в `implementation/`.

Предложение: **Role-Based 22-Archetype Reflection**, версия `dc-symbolic-1.0.0-proposed`, расчётный профиль `C-family-center-v1`. Расчёты следуют последовательной системе Марии Приемыховой. Новые английские трактовки и правила композиции обозначены как авторская редакционная надстройка, а не официальная историческая школа.

Модель содержит 38 значений:30 точек диаграммы, отдельную «Силу рода» и семь агрегатов линий/предназначений. Подготовлены 22 архетипа,26 точных троичных ключей C, структурированные позиции/каналы/правила,12 тестовых дат с полными трассами и два вручную сверенных книжных примера. Предложена структура из десяти тематических глав и технического приложения. Это результат исследования, а не сохранение старого ограничения на число глав.

## Главное различие книг

Две книги Альбины Матрикс пересекаются по содержанию и не являются независимыми школами. Они рассчитывают дополнительные родовые точки через **центр личности**. Приемыхова использует отдельную **«Силу рода»**. Эти варианты дают разные числа; выбран целостный вариант C, а альтернативный A/B сохранён отдельно для сравнения. Различается и порядок чтения/называния некоторых троек. В C для кармического ключа используется порядок вычисления: нижняя точка → внутренняя → средняя. Переставлять числа ради подходящей трактовки нельзя.

## Важная граница готовности

Все 630 PDF-страниц извлечены или распознаны и проиндексированы. Формулы, важные различия, выбранные трактовки и отдельные схемы проверены напрямую. **Полная построчная смысловая проверка всех 630 страниц и каждой повествовательной программы не завершена и здесь не заявляется.** Уровень проверки каждой страницы открыт в `research/PAGE_COVERAGE.csv`.

Расчётная основа проверена на книжных примерах. Английская библиотека является оригинальным редакционным предложением; она не доказывает эмпирическую истинность эзотерических утверждений. Обобщённый автоматический поиск всех программ C заблокирован из-за неясного правила выбора и порядка троек. Неопределённые элементы не выдаются за готовые традиционные правила. Открытые вопросы перечислены в `research/13_UNRESOLVED_DECISIONS.md`.

Приложение `~/Desktop/Isoteric` в этой среде не предоставлено. Его код, оплата, доступы и PDF не изменялись. Сравнение со старой реализацией основано только на описанных пользователем ограничениях; фактический аудит репозитория включён в задание Codex.

1. `research/01_SOURCE_AUDIT.md` и отдельные `SOURCE_A/B/C_ANALYSIS.md` — источники, содержание, независимые выводы и ограничения.
2. `research/02_THREE_BOOK_COMPARISON.md` — общие, отдельные, конфликтующие, редакционные и неподтверждённые правила.
3. `research/03_FINAL_METHODOLOGY.md`, `04_FORMULAS.md`, `05_POSITIONS_AND_CHANNELS.md` — выбранная система и точные расчёты.
4. `research/06_ARCANA_INTERPRETATIONS.md`, `07_COMBINATION_RULES.md` — оригинальные английские тексты и логика персонализации.
5. `research/REFERENCE_CALCULATIONS.md`, `12_SOURCE_TRACEABILITY.md`, `13_UNRESOLVED_DECISIONS.md` — проверка и происхождение выводов.

7. `CODEX_IMPLEMENTATION_PROMPT.md` — самостоятельное задание последующему Codex.

## Файлы данных

`data/arcana.json` —22 архетипа с редакционным происхождением, вариантами по областям и ссылками на источники. `positions.json` и `channels.json` разделяют роль, расположение и порядок чтения. `calculation_rules.json` задаёт 38 формул и отдельный альтернативный профиль. `combination_rules.json`, `contrast_pairs.json` и `karmic_patterns.json` задают явные правила композиции. `source_code_catalog.json` хранит извлечённые заголовки общих программ C с отключённым автоматическим сопоставлением. Остальные файлы включают источники, сравнение, решения, полные тестовые выходы, книжные утверждения, схему разделов, политику доступа и результаты проверок.

`schemas/` содержит исполняемые JSON Schema. `reference/` содержит независимый от приложения калькулятор и пример компоновщика без сторонних JavaScript-зависимостей. Это проверяемый эталон, а не реализация существующих платёжных маршрутов.

## Проверки

```bash
node reference/validate.mjs
python3 reference/validate_data.py
```

Для Python-проверки требуется jsonschema. Фикстуры рассчитаны отдельной Python-реализацией и сопоставлены с Node; два набора ожидаемых значений дополнительно сняты вручную с примеров книг. Результаты находятся в `data/*validation_results.json`. Тесты реального приложения, авторизации, обоих PDF и браузерного отображения здесь не выполнялись — они перечислены в отдельном ТЗ.

## Что передать Codex

Передайте **весь архив**, а не один промпт. Затем попросите выполнить `CODEX_IMPLEMENTATION_PROMPT.md`. Codex должен читать данные и решения, сохранить цену $12.90 и существующую защиту платного доступа, обновить бесплатный/платный разборы, обе темы PDF и публичный пример одним общим движком. Нерешённые формулы он не должен придумывать самостоятельно.

Исходные книги, сканы, OCR-главы и иллюстрации в архив не включены. Внутри — собственные материалы исследования и редакционные тексты со ссылками на PDF-страницы. Атрибуция не означает официального одобрения авторов или передачи прав на их книги.
